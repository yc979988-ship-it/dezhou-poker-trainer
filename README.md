# 德州扑克自适应训练器 MVP

面向新手的离线 6 人桌无限注德州扑克训练网页。它用于本地模拟和牌后复盘，**不读取真实牌局画面，不提供实时牌局提示，也不是完整 GTO 求解器**。

## 默认牌局

- 6 人桌，位置依次显示：UTG（前位）、HJ（中位）、CO（后位，按钮前一位）、BTN（按钮位，位置最好）、SB（小盲）、BB（大盲）
- 盲注 20/40，默认有效筹码 4,000（100bb）
- 100 筹码 = 1 元，仅用于界面换算
- 可选手间自动补回 4,000；盈利筹码不会被截掉
- 测试模式：牌局中不提示，结束后统一复盘
- 教学模式：每次玩家动作后立即显示简短反馈

## 常用牌友档案

在“设置 → 常用牌友”里最多保存 12 位牌友，只填昵称，并用口语化选项记录入池、limp、翻前主动、爱跟注、翻后主动和偶发失误。每局仍是 6 人桌，因此从牌友库勾选最多 5 位，剩余座位由随机对手补齐；修改后的档案从下一次“开始离线训练”生效。

档案默认只存在于当前打开的网页会话，可下载 JSON 牌友库备份后再导入。昵称仅用于本次网页显示，牌局引擎、SQLite 和确定性回放仍保存为 `bot-1…bot-5` / “对手1…对手5”，避免公网临时数据库意外留下牌友昵称；因此没有当前会话显示映射的历史回放会使用通用名称。旧版最多 5 人的 JSON 仍可导入。

这些观察会改变模拟对手的隐藏连续参数，并继续保留小幅场次漂移，不会给牌友贴永久“紧手/松凶/跟注站”标签。首版教练仍主要根据牌面、位置、赔率和通用范围复盘，不声称已经针对某位牌友完成范围求解。

## 本地启动

推荐 Python 3.11 或 3.12。在项目根目录执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
streamlit run app.py
```

浏览器打开 `http://localhost:8501`。

### 手机访问

电脑和手机连接同一局域网后执行：

```powershell
streamlit run app.py --server.address 0.0.0.0
ipconfig
```

在手机浏览器打开 `http://电脑的局域网IPv4地址:8501`。首次访问若 Windows 防火墙询问，只允许专用网络；不要在不可信公共网络暴露该端口。界面按手机竖屏设计，操作按钮采用触控尺寸。依赖安装完成后，训练与复盘均可离线运行。

## 云端访问

推荐将私有 GitHub 仓库连接到 Streamlit Community Cloud：

1. 在 Streamlit Community Cloud 选择该仓库、`main` 分支和入口文件 `app.py`。
2. Python 版本选择 3.12，点击部署。
3. 将应用设为私有；第一版仅限本人使用，不添加其他访问者。

部署完成后会得到固定的 HTTPS 网页地址，手机在任意网络都能访问，不要求与电脑连接同一 Wi-Fi，也不要求家中电脑保持开机。

免费托管实例的本地文件系统不是永久存储。默认情况下，每个打开的网页会话使用独立 SQLite，其他访客不会在回放页看到这次训练；刷新、应用重启、休眠恢复或重新部署后，旧记录可能不再可见。牌局、教练和自适应功能仍可正常使用。

`POKER_TRAINER_DB_PATH` 可让单用户本地部署固定使用一个数据库文件，但不能把 Streamlit Community Cloud 的临时磁盘变成永久存储。显式配置固定路径后不再具备默认的网页会话隔离，不应用于多人公网实例。若后续必须永久保留跨设备历史，需要增加登录与用户级数据隔离，再迁移到持久磁盘或托管数据库。

## 口径说明

- 发牌、对手策略和教练模拟使用相互独立的随机流；每手保存 seed、完整牌序和实际动作，回放不会重新调用对手策略。
- 教练只读取动作发生前的信息，不按最后输赢评价动作。
- equity 使用未知对手随机手牌的蒙特卡洛估算；outs 为常见名义 outs，未完整计入脏 outs、反向隐含赔率和对手范围。
- 对手没有永久“紧手/松凶/跟注站”标签。隐藏连续参数只用于模拟，普通界面和公开视图不会显示。
- 每满 20 手才生成画像；样本不足时直接显示“信号不足”。有明确漏洞时，下一轮仍保留至少 55% 自然随机牌局。
