## 已确认设计结论

- 引擎、对手策略、教练 Monte Carlo 使用独立随机流。
- 动作金额统一采用本街累计 `bet-to` 语义。
- 事件日志和完整牌序是回放权威数据。
- 无限注短全下不允许“补齐”式 completion；加注重开按完整加注增量累计判断。
- 底池分层按获奖资格合并同一逻辑池，避免平分时重复分配奇数筹码。
- 教练上下文在动作前冻结，不读取最后输赢。
- 统计保存分子与机会数，并按位置快照聚合。
- 每满 20 手生成一次画像；信号不足不硬凑漏洞。

## 朋友局录像校准（2026-08-28）

- 20/40 六人桌常见多人 limp，翻前加注到 120/140 后仍可能有 2—4 名玩家继续。
- limp-call 与 cold call 应显著存在，但仍受位置、牌力、加注尺度和个体隐藏参数影响，不能变成全员无脑跟注。
- 可少量出现 160—350 的非标准尺度、短码全下和明显过度继续，作为普通朋友局的偶发错误。
- 行动展示优先贴近座位，采用“位置｜跟注 120 / 加注到 350 / 全下”等短句；完整历史再按街道展开。

## 教练模型优化（2026-08-31）

- 翻前评分区分开池、隔离加注和 3bet，结合位置、前序 limp/call、有效筹码判断尺度过大或过小；合法最小加注不再等同于合理尺度。
- SB 只在首次面对加注时记录 cold-call 机会，limp 后补跟不误标为冷跟。
- 牌后说明区分纯听牌与“成牌 + 听牌”；范围敏感场景不会仅凭随机未知手牌 Monte Carlo 权益直接判为明显错误。
- 河牌一对牌面对非阻断下注再加注会提示保留对手诈唬，微小阻断下注不一刀切。
- 复盘卡常显底池赔率、随机范围基准权益、权益差、outs、命中率和听牌类型；展开后显示赔率公式、权益口径和推荐替代动作。
- 自适应画像的关键机会 reason code 已补齐，避免只记录错误、不记录正确决策导致漏洞比例失真。
- 本轮完整回归为 149 项测试通过，另通过 `compileall`；pytest 仅有既存缓存目录权限警告，不影响运行。

## 翻前动作优先级修正（2026-09-01）

- 翻前启发式升为 `6max-100bb-preflop-v3`：先判断起手牌、位置和前序动作是否支持主动加注，只有动作本身合理时才评价尺度。
- SB 持 96o 面对三名 limper 时，隔离加注会判为动作错误并推荐弃牌，不再给出“加到 280”的误导建议，也不计入尺度漏洞。
- AQs、99 等合理隔离范围仍会获得 160 对比 280 的尺度反馈；弱牌 3bet 不生成 3bet 尺度训练机会。
- SB 弱牌补齐不再推荐加注；提示改为默认弃牌、桌面极被动时可补齐。
- 下注、加注和进攻型全下不再展示跟注所需胜率、权益差或跟注赔率公式；短码全下跟注仍按实际投入展示。
- 本轮完整回归为 160 项测试通过，并通过 `compileall`；pytest 仅有既存缓存目录权限警告，不影响运行。

## 翻前细分策略 v4（2026-09-01）

- 翻前启发式升为 `6max-100bb-preflop-v4`，使用 169 种标准起手牌代码（如 `K9o`、`Q9s`、`55`），并按位置、limper 数量、开池者位置、跟注者数量、加注层级和有效后手生成动作计划。
- 每个场景明确拆分“默认动作、可接受备选、偏松/偏紧动作、明显错误”；范围判断先于尺度判断，只有范围允许的加注才会收到开池、隔离或 3bet 尺度建议。
- 复盘展开项新增“牌型｜位置｜场景”、默认线、可接受备选、适用条件和独立尺度说明；翻前与翻后使用独立版本号，历史复盘 JSON 和 SQLite 结构无需迁移。
- 关键边界已锁定：BTN 的 K9o 正常开池、BTN 的 96o 弃牌、Q9s 在 UTG/CO 的位置差异、多人 limp 时小对子跟入或补齐、A5s 面对 HJ 开池的条件性选择、AA/KK 的主动取值线。
- 新增 169 手牌、6 个位置、6 类代表场景共 6,084 个计划的不变量检查；本轮完整回归为 198 项测试通过，并通过 `compileall`。pytest 仅有既存缓存目录权限警告，不影响运行。

## 翻后结构化策略 v3（2026-09-01）

- 翻后启发式升为 `postflop-structured-v3`：先识别个人成牌强度、牌面干湿、单挑/多人和下注压力，再评价动作；最后独立检查进攻尺度。
- 随机未知手牌 Monte Carlo 只保留为可复核的参考值，不再冒充对手下注范围，也不再直接决定跟注、弃牌或加注评级。
- 听牌按原始 outs、下一张/到河牌命中窗口、成对牌面与多人折损、底池赔率综合判断；河牌明确不计算未来 outs。
- 成对牌面的策略牌力已单独校正：如 `99` 在 `T-7-2-2` 上虽由五张牌评估器显示“两对”，教练仍按中等口袋对子处理，不误当作强两对。
- 公牌成牌、底牌踢脚参与和个人成牌已分开；公牌皇家同花顺等锁定平分牌面不会被当作空气弃牌，`AK` 在 `7-7-2-3-4` 上也会明确提示踢脚摊牌值。
- 两对以上不再一律自动继续：四同花、四连顺、多人和超池压力会降级两对/三条等脆弱强牌；超大进攻尺度只对接近坚果的牌放宽。
- 翻牌跟注后英雄自己全下时按到河牌概率；仅靠深筹码隐含赔率覆盖的听牌最多评为“可以接受”，半诈唬加注不会被误记为“跟注赔率错误”。
- 复盘卡前两条策略信息常显，额外策略说明和数学细节分层展开；正确动作显示“建议打法”，错误动作显示“更好的选择”。座位行动只显示当前街最新自愿动作，弃牌和全下状态持续保留。
- 新增 23 个翻后决策场景与 17 个纯特征测试，覆盖免费过牌、河牌空气牌、公牌锁定平分、踢脚参与、顶对强弱、强成牌、强听牌、短码全下、隐含赔率、半诈唬、超池压力、多人湿润牌面、四同花/四连顺、极小下注、成对牌面和河牌 outs。
- 本轮完整回归为 240 项测试通过，并通过 `compileall`；本地 Streamlit 健康检查和 360px 手机视图的牌桌、行动按钮、牌后复盘均验证正常。
